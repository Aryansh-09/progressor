# progressor
A simple Python REPL program that solves a very niche problem.
Suppose you're solving a practice sheet, but you wish to keep track of the problems you easily tackled, problems that you need to revisit later, and problems that you couldn't do.
Progressor does exactly that. It offers a light-weight REPL interface, that is easy to operate.

## First, open a file with:

`> open (relative or absolute file path) (mode)*`

## Then, start the main function loop with:

`> start (s or safe)*`

Using start in safe mode auto-saves the content every time you make a new entry.

## Mark problems as you solve them:

`#1: (done or d | revisit or r | stuck or s)`

## Finally, save the changes by:

`#1: save`

*: Optional Argument
